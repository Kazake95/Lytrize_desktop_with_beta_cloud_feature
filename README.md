# Lytrize — Intelligent Data Analysis Platform

---

<b>Lytrize is an open-source, linux-based lightweight, offline-first data analysis tool designed for individual analysts.</b><br><br>Upload a CSV or Excel file, explore it through interactive charts and generate shareable dashboards - all locally, 
without complex setup or cloud dependency.

Currently, under development which includes cloud account & multi-device sync capabilities simultaneously. 
This .deb build is in <b>Beta-Stage</b> and not ready for in real world use. Please mind that while testing.
